# Наблюдатель — бот для практики между встречами

Telegram-бот-будильник самовспоминания. Держит нить практики между двумя
групповыми встречами в неделю: присылает случайные вопросы-напоминания,
хранит короткий дневник наблюдений, отдаёт библиотеку (лекции/музыка/глоссарий)
и тему недели. Оплата — только добровольный донат.

Всё бесплатно и без банковской карты: код бота крутится на **Render**,
данные хранятся в **Supabase** (Postgres), а внешний будильник для самого
бота — **cron-job.org**. Дальше — пошагово, займёт 30–40 минут один раз.

---

## Шаг 0. Что понадобится

- Аккаунт Telegram (у тебя уже есть)
- Почта для регистрации в Supabase, Render и cron-job.org — можно одну и ту же
- 30–40 минут свободного времени

Ничего из этого не требует привязки карты.

---

## Шаг 1. Создать бота в Telegram (BotFather)

1. Открой в Telegram диалог с **@BotFather**.
2. Отправь `/newbot`.
3. Придумай имя бота (то, что видят люди), например `Наблюдатель`.
4. Придумай username бота — должен заканчиваться на `bot`, например `nablyudatel_bot`.
5. BotFather пришлёт **токен** вида `123456789:AA...` — это `BOT_TOKEN`. Скопируй и сохрани его, он понадобится ниже.
6. (Необязательно, но приятно) отправь `/setdescription`, `/setabouttext`, `/setuserpic`, чтобы у бота была короткая подпись и аватар.

Как именно Арсен станет "администратором" бота — см. Шаг 6 в конце: это делается через сам бот (командой внутри бота), а не через BotFather, потому что BotFather не поддерживает нескольких владельцев.

---

## Шаг 2. Создать базу данных (Supabase)

1. Зайди на **supabase.com** → Sign up (можно через Google/GitHub) → New project.
2. Придумай пароль для базы (сохрани его отдельно — он нужен ниже) и выбери ближайший регион (Frankfurt/EU обычно ближе всего).
3. Дождись создания проекта (1–2 минуты).
4. Слева — **SQL Editor** → New query. Открой файл `schema.sql` из этого проекта, скопируй всё содержимое, вставь в редактор и нажми **Run**. Это создаст все таблицы и добавит несколько стартовых терминов в глоссарий.
5. Слева — **Project Settings → Database → Connection string**. Выбери вкладку **URI** и переключатель **Connection pooling** (порт обычно `6543` — он значительно стабильнее для такого типа хостинга, чем прямое подключение). Скопируй строку — это `DATABASE_URL`. Не забудь вставить в неё свой пароль вместо `[YOUR-PASSWORD]`.

Позже, чтобы добавить лекцию, трек или термин в глоссарий, не нужно трогать код —
просто открой **Table Editor → library_items** в Supabase и добавь строку. Это может делать и Арсен.

## Шаг 3. Разместить код бота (Render)

1. Зайди на **render.com** → Sign up (можно через GitHub — тогда удобнее всего).
2. Если регистрировался через GitHub: создай там новый репозиторий (например `nablyudatel-bot`) и залей в него все файлы этого проекта. Если не хочешь связываться с GitHub — Render также принимает загрузку через их CLI, но вариант с GitHub проще всего для одного человека.
3. В Render: **New → Web Service** → подключи репозиторий.
4. Настройки сервиса:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. Раздел **Environment** → добавь переменные из `.env.example`:
   - `BOT_TOKEN` — токен от BotFather (Шаг 1)
   - `DATABASE_URL` — строка из Supabase (Шаг 2)
   - `PUBLIC_URL` — узнаешь после первого деплоя, это будет вида `https://nablyudatel-bot.onrender.com` (Render покажет его сразу после создания сервиса — впиши и пересохрани переменные, сервис перезапустится)
   - `WEBHOOK_SECRET` — придумай любую длинную случайную строку (например, набери что попало на клавиатуре 30 символов)
   - `ADMIN_IDS` — пока впиши только свой Telegram ID (см. ниже, как узнать)
   - `DONATE_INFO` — текст с реквизитами Арсена
6. Нажми **Create Web Service**. Через пару минут бот должен подняться — в логах будет строка «Вебхук Telegram установлен».

**Как узнать свой Telegram ID:** напиши боту **@userinfobot** в Telegram, он пришлёт числовой ID в ответ.

Важно про бесплатный тариф Render: при отсутствии обращений сервис "засыпает" примерно через 15 минут и просыпается по первому запросу (займёт 20–30 секунд). Шаг 4 ниже (cron-job.org) решает это — постоянные обращения каждые 10 минут не дают сервису засыпать.

---

## Шаг 4. Не дать боту засыпать и включить напоминания (cron-job.org)

1. Зайди на **cron-job.org** → Sign up (без карты).
2. **Create cronjob**:
   - Title: `nablyudatel tick`
   - URL: `https://ТВОЙ-АДРЕС.onrender.com/tick/ТВОЙ_WEBHOOK_SECRET` (подставь свой `PUBLIC_URL` и `WEBHOOK_SECRET` из Шага 3)
   - Schedule: каждые 10 минут
3. Сохрани. Это единственная задача этого сервиса: он одновременно (а) держит бота "тёплым" и (б) на каждом обращении бот проверяет, кому пора прислать случайный вопрос-напоминание.

---

## Шаг 5. Проверить, что всё работает

1. Найди своего бота в Telegram по username и нажми **Start**.
2. Должно прийти приветственное сообщение с меню внизу экрана.
3. Попробуй `/journal заметил спешку`, `/library`, `/theme`, `/support`.
4. Как админ (если твой ID уже в `ADMIN_IDS`) — попробуй `/set_theme Наблюдение за нетерпением` и `/stats`.

---

## Шаг 6. Сделать Арсена администратором внутри бота

BotFather не умеет "делиться" ботом между несколькими людьми на своём уровне,
но это и не нужно — права администратора бот проверяет сам, по списку `ADMIN_IDS`.

1. Попроси Арсена написать боту `/start` и затем написать `@userinfobot`, чтобы узнать свой Telegram ID.
2. В Render → сервис → Environment → открой `ADMIN_IDS` и допиши через запятую ID Арсена, например `111111111,222222222`.
3. Сохрани — сервис перезапустится, и у Арсена появятся команды `/set_theme`, `/stats`, `/broadcast`.

Токен бота (Шаг 1) при этом можно вообще не показывать Арсену — ему для администрирования
достаточно команд внутри самого бота.

---

## Что делает каждая команда

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | все | приветствие и меню |
| `/reminders` | все | включить/выключить и настроить частоту случайных вопросов |
| `/journal <текст>` | все | сохранить короткую запись наблюдения (можно и просто текстом, без команды) |
| `/journal_show` | все | последние 5 записей |
| `/library` | все | лекции / музыка / глоссарий |
| `/theme` | все | текущая тема недели |
| `/support` | все | реквизиты для доната |
| `/set_theme <текст>` | админы | задать новую тему недели |
| `/stats` | админы | агрегированные цифры, без личных данных участников |
| `/broadcast <текст>` | админы | разослать сообщение всем — использовать редко и осознанно |

Примечание: у Telegram команды технически должны быть латиницей (правило самой платформы),
поэтому названия команд — на английском, а весь остальной текст бота и кнопки меню — на русском.

---

## Если что-то не заработало

- В логах Render (вкладка **Logs**) видно все ошибки в реальном времени.
- Самая частая причина — опечатка в `DATABASE_URL` (особенно пароль) или в `PUBLIC_URL` (должен быть без `/` в конце).
- После любого изменения переменных окружения в Render сервис нужно чуть подождать — он перезапускается и заново ставит вебхук.
